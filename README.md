# SWYNEX - Task 3 Frontend Integration

## What I Built
Expense Tracker Frontend connected to Backend API (Task 2)

## Features
- Add Expense (POST)
- View All Expenses (GET)
- Delete Expense (DELETE)
- Loading State: "Loading expenses..."
- Error State: Shows error if backend is down or validation fails
- Total calculation

## How to Run
1. Start backend: `node server.js` (Task 2)
2. Open `index.html` in browser

## Tech Stack
HTML, CSS, JavaScript, Fetch API
